# Unrailed! 2 Build Viewer

**Unrailed! 2: Back on Track** の列車ビルド(エンジン+ワゴン編成)をブラウザで組み立て・可視化し、
URLで共有できる静的Webアプリです。フレームワーク・ビルドステップ不使用(Vanilla JS)。

## 機能

- 🚂 エンジン(4種)+ワゴンを自由に編成(追加・削除・◀▶・ドラッグ&ドロップ並べ替え)
- 🔢 ワゴンごとのレベル切り替え(アイコン・数値が即時更新、カード下端はゲームと同じレベル色ライン)
- 👻 オーラの可視化 — ゴースト(青)/スーパーチャージ(金)の隣接範囲をカード上部の帯で表示。推進式エンジンの隣接+2Lvも表示
- 📦 保管庫 — エンジンとは別枠の3スロット。編成から独立しており(資材フローやチャージワゴンの影響は受けない)、レベルや拡張パーツは編成のワゴンと同じように設定可能。ドラッグで編成のワゴンと入れ替えできる。エンジンの全体バフ(トウコモティブ)は保管庫にも乗る
- ⚙ 拡張パーツ — 各ワゴンに基本3枠(+ボタンで最大6枠)。クリックで装着、ホバーで説明表示。クラフトワゴンは貨物引き寄せを初期装備、ゴースト急行に切り替えると全ワゴンの1枠目にゴーストが自動装着(手動で外すことも可能)
- ➜ 資材フロー矢印 — 貨物引き寄せ(全貨物ワゴンから。最寄りは実線=優先、遠い方は破線)/ 貨物押し出し(最寄り貨物へ)/ フロント引き寄せ(前方から)の拡張パーツから**自動生成**。拡張パーツなしではワゴン間の資材移動は発生しない(ゲーム仕様準拠)
- ⚡ 実効レベル表示 — チャージワゴン(+1)・推進式エンジン(+2)・拡張パーツのスーパーチャージ(+1)/ハイドロチャージ(+2)が乗ったワゴンは、ブースト込みのレベルでアイコン・レベル色・ステータスを表示(wiki未収録レベルは注釈付きで上限値を表示)。ワゴン自体のレベル選択は上限6
- ✎ tips の編集 — 編集モードでワゴンツールチップの「✎ 編集」から wiki 由来の tips を書き換え可能(下記参照)
- 🔍 マウスオーバー詳細 — ステータス(次レベルとの差分付き)、装着中パーツ、拡張パーツ対応表、tips、作者メモ、wikiリンク
- 🔗 URL共有 — ビルド全体を圧縮してURLハッシュにエンコード。開いた人は自動的にプレビューモード
- 📱 スマホ対応(タップで詳細表示・横スクロールで編成閲覧)

## 画像で保存 (PNG)

ヘッダーの「🖼 画像で保存」から、ビルドを1枚の画像にできます(閲覧者も使えます)。

- 入る内容: ビルド名 / タグ / コメント / 編成(矢印・オーラ・レベル色) / 拡張パーツ一覧
- 「ワゴンの説明を下に付ける」をONにすると、ツールチップと同じ内容(実効レベルのステータス・装着パーツ・作者メモなど)を追加
  - その中の tips と拡張パーツ対応表は個別にON/OFF可能
- 画面のスクリーンショットではなく専用レイアウトで描くので、PCでもスマホでも同じ画像になります
- 設定はブラウザに記憶されます

## モードの仕組み

| 状態 | モード |
|---|---|
| URLにビルドデータなし | 編集モード(作者用) |
| `#b=...` 付きURLを開く | プレビューモード(閲覧専用・レベル切替のみ可) |
| `#b=...&edit=1` 付きURL | 編集モード |
| 「編集者として記憶」を押したブラウザ | 常に編集モード |

- プレビューは閲覧専用です(レベルは「Lv.3→4」のようにブースト込みで固定表示)。
- 編集内容はブラウザに自動保存されます(URLビルドを開いていない場合)。
- 「💾 保存スロット」で名前を付けて複数ビルドを localStorage に保存できます。

## デプロイ (GitHub Pages)

1. このディレクトリ一式を GitHub リポジトリに push する

   ```bash
   git init
   git add .
   git commit -m "Unrailed! 2 Build Viewer"
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```

2. リポジトリの **Settings → Pages** で
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)` を選択して Save

3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

4. 公開ページで編成を作り「🔗 共有URLをコピー」→ そのURLを配布すればプレビューで見てもらえます

## ローカルでの動作確認

`data/wagons.json` を fetch するため、`file://` 直接ではなく http サーバー経由で開いてください。

```bash
# 例: Python
python -m http.server 8000
# → http://localhost:8000/
```

## 固定URLでのビルド配布 (更新できる共有リンク)

`#b=...` の共有URLは**その時点のスナップショット**なので、後からビルドを更新しても古いURLの表示は変わりません。
**「いつ開いても最新版」にしたい場合**は `builds/` ディレクトリ方式を使います:

1. 編集画面で「💾 保存スロット」→「⤓ 現在のビルドをJSONで書き出し」
2. 書き出したJSONをリポジトリの **`builds/`** にアップロード(例: `builds/my-build.json`)
3. `https://<ユーザー名>.github.io/<リポジトリ名>/?build=my-build.json` を配布

ビルドを更新したくなったら、また書き出して**同じファイル名で上書きアップロード**するだけ。
閲覧者は同じURLを再読み込みすれば最新ビルドが表示されます(GitHub Pagesの反映に数分かかることがあります)。

## tips を自分の文章に書き換える

現在の `data/wagons.json` の tips は**作者が編集した文章に置き換え済み**です
(wiki 原文のバックアップは `data/tips_wiki_original.json`)。

さらに書き換えたい場合:

1. 編集モードでワゴンにマウスオーバー → ツールチップの「💡 tips」内の「✎ 編集」をクリック
2. 1行1項目で書き換えて保存(まずこのブラウザの localStorage に保存されます)
3. 公開サイトにも反映したい場合は「⤓ 上書きJSONをダウンロード」で `tips_overrides.json` を書き出し、
   リポジトリの **`data/tips_overrides.json`** に置いて push

読み込み優先順位: ローカル編集 > `data/tips_overrides.json`(あれば) > `data/wagons.json`

## データソース

- `data/wagons.json` — [Unrailed2@wiki](https://w.atwiki.jp/unrailed2/pages/40.html) から抽出したワゴン/エンジンデータ
- `data/expansions.json` — [拡張パーツページ](https://w.atwiki.jp/unrailed2/pages/56.html) から抽出した説明・レベル加算値
- `data/materials.json` — 消費資材の定義(どのワゴンが木材/鉄/レールを消費するか。編集して調整可)
- `assets/materials/` — 資材アイコン(木材/鉄/レール/木材+鉄)。矢印上を流れるアイコンとワゴンの消費表示に使用
- `data/tips_overrides.json` — (任意) 作者による tips の上書き
- `assets/wagons/` — ワゴンアイコン(Lv.1〜6。Lv.7以上は見た目がLv.6と同じためLv.6を流用)
- `assets/expansions/` — 拡張パーツアイコン(13種)

## ファイル構成

```

assets/         … アイコン画像
builds/         … 固定配布用ビルドJSON(任意)
```
